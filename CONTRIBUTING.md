# Contributing to NetPilot

Thanks for helping improve NetPilot.

## Feedback and bug reports

Use [GitHub Issues](https://github.com/karen101996/netpilot-releases/issues) for feature requests and non-sensitive bugs. Include:
- NetPilot version and Windows version
- Device vendor and model, if relevant
- Exact command and observed behavior
- Expected behavior
- Sanitized console output, **without** credentials, private IPs or device configuration

## Development model

This repository distributes public NetPilot files and update metadata. Development and code review currently happen in a separate private repository. Pull requests to this distribution repository may not be the appropriate route for feature development; please start with an issue.

## Security

Never commit credentials, device backups, or internal network details. Read [SECURITY.md](SECURITY.md) before reporting a security problem.
